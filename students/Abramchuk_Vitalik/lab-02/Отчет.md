## Часть 3. Domain Layer

### Основные сущности

- **Notebook** — тетрадь, содержащая заметки
- **Note** — заметка с текстом и метками
- **Tag** — метка для классификации

### Бизнес‑правила

1. Заметка должна принадлежать тетради.
2. У заметки может быть несколько меток.
3. История изменений должна сохраняться при редактировании.
4. Совместное редактирование допускается несколькими пользователями.

## Часть 4. Application Layer

### Входящие порты

```python
class CreateNoteUseCase:
    def create(self, notebook_id: str, content: str): pass
```

```python
class GetNoteUseCase:
    def get(self, note_id: str): pass
```

### Исходящие порты

```python
class NoteRepository:
    def save(self, note): pass
    def find_by_id(self, note_id): pass
```

```python
class NotificationService:
    def notify(self, message: str): pass
```

### Application Service

```python
class NotesService(CreateNoteUseCase, GetNoteUseCase):
    def __init__(self, repository, notification_service):
        self.repository = repository
        self.notification_service = notification_service
```

## Часть 6. Dependency Injection

```python
class DependencyContainer:
    def __init__(self):
        self.note_repository = InMemoryNoteRepository()
        self.notification_service = ConsoleNotificationService()
```
