# Архитектурная диаграмма notes-service

## Диаграмма слоёв

```
┌──────────────────────────────────────────────────────────────┐
│                     Infrastructure Layer                     │
│  ┌──────────────────┐   ┌──────────────────────────────────┐ │
│  │ REST API         │   │ InMemoryNoteRepository           │ │
│  │ Controllers      │   │ ConsoleNotificationService       │ │
│  └───────────┬──────┘   └──────────────────────────────────┘ │
└──────────────┼───────────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────────┐
│                     Application Layer                        │
│  ┌──────────────────┐   ┌──────────────────────────────────┐ │
│  │ In Ports         │   │ Out Ports                        │ │
│  │ (Use Cases)      │   │ (Repositories, Notifications)    │ │
│  └───────────┬──────┘   └──────────────────────────────────┘ │
│              │                                               │
│  ┌───────────▼────────────────────────────────────────────┐  │
│  │ NotesService (бизнес-логика работы с заметками)        │  │
│  └────────────────────────────────────────────────────────┘  │
└───────────────────────────┬──────────────────────────────────┘
                            │
                            ▼
┌──────────────────────────────────────────────────────────────┐
│                         Domain Layer                         │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐        │
│  │ Note         │  │ Notebook     │  │ Tag          │        │
│  │ (Entity)     │  │ (Entity)     │  │ (ValueObject)│        │
│  └──────────────┘  └──────────────┘  └──────────────┘        │
└──────────────────────────────────────────────────────────────┘
```

### Описание портов и адаптеров

| Тип                   | Название                   | Назначение                                         |
| --------------------- | -------------------------- | -------------------------------------------------- |
| **Входящий порт**     | CreateNoteUseCase          | _Интерфейс для создания заметки_                   |
| **Входящий порт**     | GetNoteUseCase             | _Интерфейс для получения заметки по ID_            |
| **Исходящий порт**    | NoteRepository             | _Интерфейс для хранения и поиска заметок_          |
| **Исходящий порт**    | NotificationService        | _Интерфейс для уведомлений (консоль, email и др.)_ |
| **Входящий адаптер**  | NoteController (REST)      | _REST API для создания и получения заметок_        |
| **Исходящий адаптер** | InMemoryNoteRepository     | _Реализация репозитория заметок в памяти_          |
| **Исходящий адаптер** | ConsoleNotificationService | _Реализация уведомлений через консоль_             |
