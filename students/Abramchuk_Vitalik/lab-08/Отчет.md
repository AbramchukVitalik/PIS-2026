## Ход выполнения работы

### 1. Request Service (Notes Service)

**Bounded Context:** Управление заметками и тетрадями

**API:**

- POST /notes
- GET /notes/{id}
- PUT /notes/{id}
- POST /notebooks

**Ответственность:**

- создание заметок
- редактирование
- хранение истории изменений
- работа с тетрадями

---

### 2. Group Service (Tags Service)

**Bounded Context:** Управление метками

**API:**

- POST /tags
- GET /tags
- POST /notes/{id}/tags

**Ответственность:**

- создание меток
- привязка меток к заметкам

---

### 3. Event Bus (RabbitMQ)

**События:**

- NoteCreated
- NoteUpdated
- TagAssigned
- NotebookCreated

**Скриншот RabbitMQ Management:**

_[exchange: notes-events / queues / bindings]_

---

### 4. API Gateway

**Маршрутизация:**

- /notes/\*\* → Notes Service
- /tags/\*\* → Tags Service
- /notebooks/\*\* → Notes Service

**Конфигурация:**

```nginx
events {}

http {
    server {
        listen 80;

        location /notes/ {
            proxy_pass http://notes-service:8000/;
        }

        location /tags/ {
            proxy_pass http://tags-service:8001/;
        }

        location /notebooks/ {
            proxy_pass http://notes-service:8000/;
        }
    }
}
```

## Вывод

В ходе работы система "Заметки Пишем вдвоём" была разделена на микросервисы.  
Реализованы отдельные bounded contexts для заметок и меток.  
Коммуникация между сервисами осуществляется через RabbitMQ (event-driven архитектура).  
API Gateway обеспечивает единый вход и маршрутизацию запросов.
