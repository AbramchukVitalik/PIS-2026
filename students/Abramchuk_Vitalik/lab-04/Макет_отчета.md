## Цель работы

Реализовать прикладной слой (Application Layer) с разделением операций на команды (изменяют состояние) и запросы (читают данные) по паттерну CQRS.

## 1. Команды (Commands)

### Созданные команды

1. **CreateNoteCommand** — создание заметки  
   Поля: `title`, `content`, `author_id`, `tags`  
   Валидация: title/content не пустые, author_id обязателен  
   Файл: `application/command/create_note_command.py`

2. **EditNoteCommand** — редактирование заметки  
   Поля: `note_id`, `editor`, `new_content`  
   Валидация: все поля обязательны  
   Файл: `application/command/edit_note_command.py`

3. **AddTagCommand** — добавление метки  
   Поля: `note_id`, `tag`  
   Файл: `application/command/add_tag_command.py`

### Пример кода команды

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class CreateNoteCommand:
    title: str
    content: str
    author_id: str
    tags: list = ()

    def __post_init__(self):
        if not self.title or not self.title.strip():
            raise ValueError("Title cannot be blank")
        if not self.content or not self.content.strip():
            raise ValueError("Content cannot be blank")
        if not self.author_id:
            raise ValueError("author_id is required")
```

## 2. Command Handlers

### Созданные обработчики

1. **CreateNoteHandler**  
   Шаги: валидация → создание Note → сохранение → возврат ID  
   Файл: `application/command/handlers/create_note_handler.py`

2. **EditNoteHandler**  
   Шаги: загрузка → изменение → сохранение  
   Файл: `application/command/handlers/edit_note_handler.py`

3. **AddTagHandler**  
   Шаги: загрузка → добавление метки → сохранение  
   Файл: `application/command/handlers/add_tag_handler.py`

### Пример кода handler

```python
class CreateNoteHandler:
    def __init__(self, repository):
        self.repository = repository

    def handle(self, command: CreateNoteCommand) -> str:
        note = Note(
            title=command.title,
            content=command.content,
            author_id=command.author_id,
            tags=list(command.tags)
        )
        self.repository.save(note)
        return note.id
```

## 4. Query Handlers

### Созданные обработчики

1. **GetNoteByIdHandler**  
   Репозиторий: NoteRepository  
   Возвращает: NoteDto  
   Файл: `application/query/handlers/get_note_by_id_handler.py`

2. **SearchNotesHandler**  
   Репозиторий: NoteRepository  
   Возвращает: список NoteDto  
   Файл: `application/query/handlers/search_notes_handler.py`

### Пример кода

```python
class GetNoteByIdHandler:
    def __init__(self, repository):
        self.repository = repository

    def handle(self, query: GetNoteByIdQuery):
        note = self.repository.find_by_id(query.note_id)
        if not note:
            return None
        return {
            "id": note.id,
            "title": note.title,
            "content": note.content,
            "tags": getattr(note, "tags", []),
            "history": getattr(note, "history", [])
        }
```

## 5. Application Service (Фасад)

**Реализованный сервис:** `NoteService`

### Методы

| Метод                   | Тип     | Возвращает    |
| ----------------------- | ------- | ------------- |
| `create_note(command)`  | Command | ID            |
| `edit_note(command)`    | Command | void          |
| `add_tag(command)`      | Command | void          |
| `get_note_by_id(query)` | Query   | NoteDto       |
| `search_notes(query)`   | Query   | List[NoteDto] |

### Пример кода

```python
class NoteService:
    def __init__(self, repository):
        self.create_handler = CreateNoteHandler(repository)
        self.edit_handler = EditNoteHandler(repository)
        self.tag_handler = AddTagHandler(repository)
        self.get_handler = GetNoteByIdHandler(repository)

    def create_note(self, command):
        return self.create_handler.handle(command)

    def edit_note(self, command):
        self.edit_handler.handle(command)

    def add_tag(self, command):
        self.tag_handler.handle(command)

    def get_note_by_id(self, query):
        return self.get_handler.handle(query)
```
