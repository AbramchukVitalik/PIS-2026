## Ход выполнения работы

### 1. Write Model (Агрегат)

**Сущность:** Note

- Инварианты внутри агрегата
- События при создании и изменении
- История изменений

---

### 2. Read Model (Projection)

**Сущность:** NoteView

- Денормализованная структура
- Оптимизирована под чтение
- Быстрый доступ без логики домена

---

### 3. Event-Driven Synchronization

События:

- NoteCreated → создаёт NoteView
- NoteEdited → обновляет NoteView

---

### Projection Handler

```python
class NoteProjection:

    def __init__(self):
        self.views = {}

    def handle(self, event):
        if event.__class__.__name__ == "NoteCreated":
            self.views[event.note_id] = {
                "note_id": event.note_id,
                "notebook_id": event.notebook_id,
                "author_id": event.author_id,
                "content": event.content,
                "last_updated": event.created_at
            }

        if event.__class__.__name__ == "NoteEdited":
            view = self.views.get(event.note_id)
            if view:
                view["content"] = event.content
                view["last_updated"] = event.edited_at
```
