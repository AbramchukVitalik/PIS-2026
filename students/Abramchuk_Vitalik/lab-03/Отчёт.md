## 1. Value Objects

### Созданные Value Objects

1.  **Tag** --- метка заметки (иммутабельный объект)
    - имя не может быть пустым\
    - длина ≥ 2 символов
2.  **NoteHistoryEntry** --- запись истории изменений
    - хранит снимок старого содержимого\
    - дату и редактора
3.  **NoteStatus** --- статус заметки (`DRAFT`, `ACTIVE`, `ARCHIVED`)

### Пример кода Value Object

```python
@dataclass(frozen=True)
class Tag:
    name: str

    def __post_init__(self):
        if not self.name or len(self.name.strip()) < 2:
            raise ValueError("Tag name must contain at least 2 characters")
```

## 2. Entities

### Notebook --- тетрадь

**Инварианты:** - название не может быть пустым - нельзя добавить одну и
ту же заметку дважды

```python
class Notebook:

    def __init__(self, notebook_id: str, owner_id: str, title: str):
        if not title:
            raise ValueError("Notebook title cannot be empty")

        self._id = notebook_id
        self._owner_id = owner_id
        self._title = title
        self._notes_ids: list[str] = []

    def add_note(self, note_id: str):
        if note_id in self._notes_ids:
            raise ValueError("Note already in notebook")
        self._notes_ids.append(note_id)
```

## 3. Aggregate Root --- Note

**Aggregate Root:** `Note`

**Value Objects внутри:** `Tag`, `NoteHistoryEntry`, `NoteStatus`

### Инварианты агрегата

№ Инвариант Где проверяется

---

1 Содержимое заметки не может быть пустым Конструктор
2 Нельзя редактировать архивную заметку `edit()`
3 История ≤ 50 записей `edit()`
4 ≤ 10 меток `add_tag()`
5 Нельзя добавить одинаковую метку `add_tag()`
6 Каждое изменение генерирует Domain Event методы агрегата

### Код Aggregate Root

```python
class Note:

    MAX_TAGS = 10
    MAX_HISTORY = 50

    def edit(self, editor_id: str, new_content: str):
        if self._status == NoteStatus.ARCHIVED:
            raise InvariantViolation("Cannot edit archived note")

        self._history.append(
            NoteHistoryEntry(
                editor_id=editor_id,
                content_snapshot=self._content,
                edited_at=datetime.now()
            )
        )

        if len(self._history) > self.MAX_HISTORY:
            self._history.pop(0)

        self._content = new_content
        self._status = NoteStatus.ACTIVE
```

## Контрольные вопросы

**1. Отличие Value Object от Entity**\
Value Object определяется значением, Entity --- идентификатором.

**2. Зачем Aggregate Root инкапсулирует доступ?**\
Чтобы гарантировать соблюдение инвариантов.

**3. Роль Domain Events**\
Фиксация значимых изменений (например, `NoteEdited`).

**4. Где проверяются инварианты?**\
В конструкторе и методах `edit()` и `add_tag()`.

**5. Почему VO иммутабельны?**\
Для предсказуемости и безопасности модели.
